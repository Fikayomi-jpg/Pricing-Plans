# Pricing Plans 💰

A simple and responsive **Pricing Plans webpage** built using only **HTML and CSS**.  
This project showcases different subscriptions in a clean and modern layout.

---

## 📌 Features

- Clean pricing card layout
- Modern UI using only CSS (no JavaScript)
- Multiple pricing tiers (Basic, Pro, Premium)
- Lightweight and fast-loading page

---

## 🛠️ Built With

- HTML5
- CSS


## 🚀 How to Use

- Clone the repository:
  git clone https://github.com/Fikayomi-jpg/Pricing-Plans.git

- Open the project folder:
  cd Pricing-Plans

- Open `Price.html` in your browser
